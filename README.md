Following repo demonstrates a console utility for generating test data using provided data schema. Application is using argparse as a user interface for processing of various json strings and files.

Usage example with provided data_schema:

    python3 ConsoleUtility.py --file_count=3 --file_name=example_data --prefix=count --data_schema="{"date": 
    "timestamp:","name": "{rndm_uuid}", "type": "['client', 'partner', 'government']","age": "int:rand(1, 100)
    "}"

Another example with file:

    python3 ConsoleUtility.py . --file_count=3 --file_name=example_data --prefix=count 
    --data_schema=./path(abs or relative)/to/schema.json


PARAMS DESCRIPTION:
--files_count param takes single number as a value. It states how many files will be generated by an 
application.

--file_prefix argument may have either random, uuid, count value. It is used for filename generation.

--data_lines param declares how many lines are saved within json file.

--clear_path argument is used to clear all json files at a given path.

--file_name param have a string value used as a filename.

--path_to_save_files holds string with either absolute or relative path where json file will be created.

Utility generate three types of files:
*config.ini configuration params
*(generic_name).json files which store json strings.
*sample.log file with logs of every operation done by an application
